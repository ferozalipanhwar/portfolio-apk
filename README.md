# Panhwar Portfolio - Android Application

A modern, high-performance Android portfolio application for **Feroz Ali Panhwar** (Full Stack & React Native Developer), crafted using **Kotlin**, **Jetpack Compose**, and **Material Design 3**.

---

## 🚀 Key Features

1. **Cyberpunk Hero Section**:
   - Holographic gradient typography and rotating cyber halo profile avatar.
   - Dynamic quick-tech badges and quick action buttons.

2. **About Me & Capability Badges**:
   - Highlighting expertise in Web Development (MERN Stack), Mobile Engineering (React Native & Android), and Architectural Problem Solving.
   - Pro Developer credential badge.

3. **Tech Stack Arsenal**:
   - Filterable skills directory categorized into Frontend, Backend, Mobile, and Tools.
   - Individual skill cards with proficiency indicators, brand colors, and glowing borders.

4. **Professional Journey (Career Timeline)**:
   - Chronological engineering roles with central glowing cyan connector nodes.
   - Detailed job descriptions, company tags, and key architectural contributions.

5. **Featured Creations**:
   - Showcase of 8 signature projects including *Alif Akh Academy* (LMS), *Autaaq* (Sindhi cultural platform), *EasyDocs* (QR attendance), *Agriculture App*, *Share Ride*, *Fast Food Store*, *UC Complaint System*, and *Voice Cart*.
   - Filterable by Web, Mobile, and System categories with direct demo and repository links.

6. **Hire Me CTA & Availability Beacon**:
   - Live pulsating status beacon indicating freelance project availability.
   - Direct integration with WhatsApp chat and contact triggers.

7. **Creative Gallery**:
   - Visual collection of workspace setups, developer cockpit photos, and coding sprint sessions.
   - Fullscreen image preview modal.

8. **Technical Blogs**:
   - 6 in-depth articles on MERN stack architecture, React Native performance, Java vs. Python, WebSockets, clean JavaScript, and Python web development.
   - Native full article reader dialog.

9. **Interactive Contact Form**:
   - Material 3 input validation with animated submission feedback.
   - Intent triggers for Email, Phone, and WhatsApp.

10. **Curriculum Vitae (Resume)**:
    - Dedicated CV view with education, skill matrices, work history, and native share sheet integration.

---

## 🛠️ Architecture & Tech Stack

- **Language**: Kotlin 2.1.0
- **UI Framework**: Jetpack Compose (BOM 2025.02.00) + Material 3
- **Image Loading**: Coil 2.7.0
- **Design System**: Material Design 3 with custom Cyberpunk dark theme
- **Build System**: Gradle 8.8+ with Kotlin DSL (`build.gradle.kts`) and Version Catalog (`libs.versions.toml`)
- **Min SDK**: 24 (Android 7.0+)
- **Target SDK**: 35 (Android 15)
